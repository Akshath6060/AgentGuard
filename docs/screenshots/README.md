# Screenshots

Capture these from a freshly seeded demo workspace and commit them here with the
filenames below, so the links in the root `README.md` resolve.

| File | What to capture |
|---|---|
| `dashboard.png` | Overview — spend, risk distribution, live agent activity |
| `agents.png` | AI Agents list with spend against limits |
| `policies.png` | Policy Intelligence — categories, chunks, indexing state |
| `allow.png` | An `approved` transaction and its settled payment |
| `review.png` | A `review` transaction with funds held, plus the Approval Center |
| `block.png` | A `blocked` transaction showing `TRANSACTION_LIMIT` |
| `audit.png` | Audit Logs timeline |

Before capturing: re-seed, then run **ALLOW first**, then REVIEW, then BLOCK
(see the demo-order note in `DEMO_SCRIPT.md`).

Do not include any real API key, secret, or `.env` content in a screenshot.
